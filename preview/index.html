About Shuvi UI Preview

SAFE DEMONSTRATION

This static website is a design preview of the Shuvi Windows AI computer agent. It does not collect API keys, connect to a local device, call AI models or run external actions. The underlying Windows app is built with Tauri, Rust and TypeScript, and requires explicit per-action approval for sensitive tools.

All workflow metrics in the browser preview are fictional illustrative samples. Visit the GitHub repository for ongoing source implementation and acceptance status.
